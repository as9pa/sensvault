# sensvault

easy place to store sensitivities across a library of games

sort by name, game, sens, dpi, cm/360
sensitivities are stored in `%APPDATA%\SensVault\data.json`

# download

requires windows x64.

| [releases](https://github.com/as9pa/sensvault/releases) | size | needs .NET? |
|---|---|---|
| `SensVault-...-standalone.exe` | ~62 mb | **no** — built in runtime |
| `SensVault-...-needs-dotnet10.zip` | ~90 kb | **yes** — [.NET 10 desktop runtime](https://dotnet.microsoft.com/en-us/download) |

take the standalone unless you already have .NET 10 installed
